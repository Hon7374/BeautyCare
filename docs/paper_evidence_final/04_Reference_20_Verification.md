The source title uses `&`, not the word `and`. The exact ICCIT reference style should still be checked against the conference template because the manuscript is absent from the workspace.

## Related-work fit

The source is appropriate for claims about comparative SAST/DAST evaluation, OWASP/CWE-oriented security testing, and tool effectiveness. It does not by itself validate BeautyCare’s CSRF implementation, k6 results, voucher policy, or production security. Those project-specific claims require BeautyCare evidence.

## Replacement paragraph

“Qadir et al. conducted an empirical comparison of open-source static and dynamic application security testing tools across real-world Web applications. Their findings motivate the use of complementary SAST and DAST techniques, while also showing that tool effectiveness varies by vulnerability category and severity. In this study, that prior work is used to motivate the security-evaluation methodology; the BeautyCare-specific results are reported separately from the claims established by the cited study.”
